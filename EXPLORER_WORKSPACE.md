# Explorer Workspace

Milestone 4 introduces a URL-addressable workspace around every archive category.

## Modes
- **Explorer**: dense keyboard-navigable master/detail index.
- **Gallery**: existing visual cards with persistent preview.
- **Analysis**: result-set coverage and category statistics.

## URL state
The query string now preserves search, filters, sort, page, selected record, and workspace view. Browser reloads and shared URLs restore the same workspace context.

## Keyboard interaction
In Explorer mode, focus a record and use the up/down arrows to move selection. The live dossier updates without navigation.

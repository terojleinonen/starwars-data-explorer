# Portfolio Polish

This pass completes the presentation layer of Starwars Data Explorer.

## Landing experience

- Replaced the static orbital illustration with a CSS/SVG tactical constellation table.
- Added interactive archive nodes, connected routes, depth, scanning instrumentation, and a floating signal dossier.
- Reframed the hero around an intelligence-console narrative and strengthened the cinematic hierarchy.

## Theme direction

- Light mode now uses warm stone, parchment, aged metal, and muted observatory blue rather than white application surfaces.
- Dark mode uses a deeper near-black space field with restrained moonlit blue atmosphere.
- Both themes share geometry and information hierarchy while using different materials and lighting.

## Cards and surfaces

- Holo cards now use category-derived accents, layered material gradients, dossier markings, and controlled highlights.
- People, planets, starships, vehicles, species, and films have distinct but restrained colors.
- Shared record panels now use semantic surfaces instead of dark hard-coded gradients in light mode.

## Interaction and accessibility

- Motion is restrained and disabled through reduced-motion preferences.
- Interactive map nodes remain normal links and work without pointer interactions.
- Existing keyboard navigation, focus treatment, responsive layouts, and semantic headings remain intact.

- ESLint passes.
- TypeScript passes.
- Next.js production build passes.
